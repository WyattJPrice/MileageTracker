
# Mileage Tracker

Interactive visualization charts synced to [Intervals.icu](https://intervals.icu) (Garmin-connected) and a log of (mostly) every race I've completed.


![Logo](https://wyattprice.dev/projects/Miles.png)


## Features

- Large interactive chart of every week
- Daily view when zoomed in
- Individual charts for each training block (8th,9th,10th,11th)
- Automatic Sync to intervals.icu
- Race logging using telegram bot (also connects to [wyattprice.dev](https://wyattprice.dev))


## Tech Stack

Next.js, Shadcn, Tailwind, Upstash Redis, Telegram
